## How to Use This Guide (30–90 minute sessions)

1. Pick one repo or article from a section.
2. Read the README or article for 20–30 minutes and take notes (one-paragraph summary).
3. Clone or open the code, run any quickstart if available (30–60 minutes).
4. Make a tiny change: add a print/log, tweak a parameter, or write a one-file experiment.
5. Commit, push, and optionally open an issue/PR sharing what you learned. Be proud! 🚀

Project ideas:
- Reproduce an example from a repo and document steps.
- Compare two repos' approaches to context and token reduction.
- Build a tiny wrapper that loads an open-weight model and runs a short prompt.
